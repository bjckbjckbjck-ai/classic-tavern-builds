# v0.59.0 玩法基准与 AI 经营报告

这是本项目权威规则引擎生成的离线实验，不是真实玩家大数据，也不是官方炉石天梯榜。阵容建议来自现有卡池和机制；强度标签只用于下面明确的基准。测试不修改卡牌数值。

完成 **312 场八人完整对局 / 2496 个席位**，实际结算 **17,538 场对战**；另做 **28,800 场固定阵容对战**，共 **46,338 场战斗**。覆盖29英雄、12畸变和关闭畸变、饰品开/关。

## 如何成型，以及为什么不能盲追核心

| 玩法 | 操作与转型条件 |
| --- | --- |
| 空中海盗跳操 | 无赖先手启动，擎旗给衍生亡语，伊丽扎和瑞文保护在后。 |
| 手牌合唱鱼 | 裁脍留手而非打出；低音先死拉手牌，保护合唱与复仇核心。 |
| 补盾亡语机械 | 亡语机械补盾，激光先破敌方盾；偏折不要全部放在最先攻击位。 |
| 狼爹召唤 | 狼爹在鹦鹉左侧，猛猿和熊妈妈后置；亡语填场需要空位。 |
| 鹦鹉跳蛙 | 跳蛙先送，鹦鹉在其后进击，瑞文后置；招募期用响尾蛇累积复生。 |
| 诗心叠盾龙 | 泰蕾与执行者夹诗心，增强幼龙相邻高收益龙；盾层与战斗新增增益可保留。 |
| 受伤成长野兽 | 圆头进击带动受伤链；哈气和炫彩在招募与战斗间持续成长。 |
| 卡雷战吼龙 | 卡雷铜须经营，法术唤魔师补成长；战吼循环结束后换掉临时资源位。 |
| 灵魂弹亡语恶魔 | 先积累恶魔点数，再让嘲讽亡语恶魔吸火、喷子后排输出。 |
| 娜拉法术混合 | 法术供给养多族，优先狂战/盾载体；打决赛可用已养大的组件替换产法术位。 |
| 磁力复制机械 | 磁力优先死神或偏折，拳手接复制；无人机与产磁力组件供长期经营。 |
| 宰割复生亡灵 | 宰割与阿努巴拉克养全局攻击，复生随从承载攻击次数，姐妹后排。 |
| 战吼烈毒鱼 | 小瞎眼夹在国王与奔波尔霸之间，铜须和达卡莱后置；招募期用毒鳍补烈毒。 |
| 特塞斯买卖海盗 | 特塞斯霍格供资源，佩姬养狂战；决赛可把经济位换成战斗组件。 |
| 永恒骑士亡灵 | 骑士先交换、召唤者补骑士，工匠与姐妹支持复生；逐局计数决定真实上限。 |
| 吞食商店恶魔 | 邪能元素/商店饰品养店，再吞食；后期评估卖掉战吼组件换输出。 |


- 鹦鹉跳蛙需要亡语种子、传播、亡语倍增和承接者协同；只有跳蛙不能把一堆大身材换掉。金色优先和站位不同，强度会变化。
- 吞食、买卖、卡雷、磁力、亡灵依赖持续经营。表中统一的静态身材不等于它们在实战中能获得的身材，也未给亡灵/恶魔预置额外全局计数。
- 决赛只剩一轮收益时，资源组件的价值降低；已有高攻狂战、多层盾和手牌承接者可能比再拿一张经济核心更重要。

新策略改变：整队替换收益、血量相关的成长回合预算、缺组件折扣、残血即战力底线、手牌合唱的留手价值、诗心/小瞎眼相邻站位。大身材不是自动保留，核心也不是自动优先。所有触发仍受真实金币、共享池、手牌和场位约束。

新组记录了 7444 次由大身材换入较小身材的换牌。这只是行为计数，并不意味着每次都正确或每次都是核心。最高难度的额外护甲、12币上限、4币起始及核心偏好抽取**没有混入**上述对照。

**本次结论：吃鸡率提高，但前四率下降；平均名次的区间跨过0，没有证据说明平均排名稳定提高。** 新策略更愿意牺牲当前身材完成组合，上限提高也伴随转型失败风险。下一步应优化中期止损与资源位腾格，不应只以吃鸡率宣布全面变强。

## 实验口径与复现
