实际卡库为 **199 条随从定义、147 张在池随从、22 名英雄、37 张法术**。鱼人与亡灵各有 19 张可用成员，包含全部种族融合怪；多族牌只占一个实体和一份共享池，不把成员数相加当作总牌数。精确数据在 [catalog.json](catalog.json)。完整历史版本选择、官方来源与后续名单见[七族设计](../../v0.50.0-七族卡池设计.md)。

六张使用各自原卡 ID 的图像，没有借用别的随从占位。[来源与 SHA-256](art-sources.json) 记录下载地址和对应关系；原始美术不随本公开证据目录重新分发。中文名核对与历史效果选择分开，最新数据库中的效果不覆盖本次选定的历史版本。

## 规则与界面

- 每回合使用随从、整局使用战吼随从分别计数。磁力使用算一次；召唤、铜须重复战吼和战斗重触发不增加使用数。回合末成长与目标预览读取同一计数。
- 永久售价按招募实体 UID 回写；复生、变金回手、鲈鱼召唤和战斗中新生成随从需保持正确归属。结算收据避免重复领取，不能把战斗临时属性带回招募。
- 产币生成实际零费酒馆币卡，遵守十手牌上限。战斗奖励与宰割共享容量及产生顺序，不能播放成功入手却在结算时静默丢牌。
- 商店闲置时突出插画、星级和属性，选中／悬停显示姓名。叠层徽记仍可见；尸体提炼师增加实际售价小铸币徽章。
- 详情把当前收益、使用次数和售价提前；未印刷且当前也没有的 0／0 关键词不再占行，消耗完的印刷层数仍保留。
- 资源入手增加有厚度与凸起边缘的 3D 铸币，沿原有效果轨迹飞向手牌；2D 模式绘制同类铸币。沿用计数音效，本轮没有新增音频资源或实听验收。

## 验证范围

最终相关功能回归 **42 套、1331 条断言通过**；六张专用 94 条，原生 UI **20 条**，实际截图 **17 张**。规格与质量复评通过，未把多次重跑重复累计。

[results.json](results.json)、[logs](logs) 与 [native.log](native.log) 保存本次功能回归及 Windows OpenGL 原生 UI 结果；[source-files.json](source-files.json) 记录被测文件哈希，[manifest.json](manifest.json) 记录证据哈希。旧测试中的随机种族筛选改为成员判定，保留星级、数量、UID 和库存约束；印刷主种族与饰品元数据没有机械替换。

原生 UI 实际发送拖拽和点击事件，检查融合怪购买仅扣一次费用、零费酒馆币入手后实际使用、3D 纹理跟随选中状态、手机首次点击不出牌。截图来自 Godot 4.6.1 Windows 原生窗口，没有进行图像美化。QA 固定阵容、关闭测试驱动的自动推进，并在截图时固定可见倒计时 76 秒；产品没有新增暂停。

**手机截图是 Windows 的手机布局开关模拟，不是 APK 或实体安卓。** 本阶段没有新安装包、双客户端验证、音频实听、帧率测量或胜率平衡分析；现有完整对局测试仅验证可结束及池守恒。不能以静态截图证明动画流畅或长局性能。
