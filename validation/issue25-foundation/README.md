# #25 七族规则基础与 #18 界面复查

2026-09-16，v0.50.0 开发阶段。源码基线 `eff8b44`，当前工作分支 `3d`。**本阶段未发布 APK／EXE，公开安装包仍为 v0.49.0。** 十二张候选随从、四张候选法术与退役替换尚未加入正式数据，不能将本阶段称作卡池扩展已交付。

## 已实现的规则

- 新增统一 `tribes.gd`：旧 `tribe`、双族 `tribes` 和 `all_tribes` 使用相同成员语义；只包含当前七族，法术不是种族随从。
- 招募、战斗、亡灵全局、跳蛙、磁力、英雄、酒馆法术、饰品资格／推荐、AI 与触控预览全部迁移。双族和全部种族只占一个实体／一个池计数／一次买卖事件。
- 光牙、蜡烛女王、混合增益法术等“每类一个”使用最大匹配；一个 UID 最多得到一份，一只全部种族加六种单族可以覆盖七个不同随从。等价选择使用主机 RNG。
- AI 按实际可增益实体估计混合收益，一个全部种族不等于七个目标。饰品各族门槛中，它各贡献一个，不能单独满足两／三随从门槛。
- 卡库拒绝空／重复／未开放类型及错误字段；缺少旧主族的合法双族卡，加载默认值后仍能通过同一校验。

## 已实现的界面

- 手牌、详情及收藏随从有独立紫金星级旗标，金色紧凑卡的标记不再压住星级。
- 卡面种族胶囊显示双族或“全部”；详情列出七族。图鉴任一种族都能找到对应多族牌，“所有种族”和“全部种族随从”分开。
- 法术／英雄搜索不再误加“中立”关键词。
- 修复实际截图发现的阶段横幅覆盖收藏册：进入图鉴或菜单时隐藏已有阶段横幅，阅读期间不新建。
- 双端微扇形规则保留。没有更改暂停、回合计时、难度加成或共享池数量。

## 证据与边界

[results.json](results.json) 汇总 **28 套 headless 功能回归、919 条断言**；[logs](logs) 保存对应本次日志。新增四套共 **112 条**，涵盖 128 组与穷举最优解对照的匹配图、真实磁力／毒鳍操作、全局加攻、每类一个、共享池与类型筛选。现有完整对局测试仅检查结束及池守恒，没有胜率报告或平衡调整。

[native.log](native.log) 是 Godot 4.6.1 Windows OpenGL 实际运行，**32 条 UI 断言通过，退出 0**，并产生九张未经图像编辑的截图。运行脚本是源仓库 `tests/tribes_ui_v50_test.gd`：

```powershell
& 'D:/godot/Godot_v4.6.1-stable_win64.exe/Godot_v4.6.1-stable_win64_console.exe' --path . --script res://tests/tribes_ui_v50_test.gd
python -X utf8 scripts/verify.py tribes_v50_test tribes_recruit_v50_test tribes_combat_v50_test tribes_ui_v50_test
```

这是原生窗口输入事件和真实渲染，不是仅检查坐标。验证磁力拖拽只结算一次、战吼拖入后等待选择、点击高亮融合目标后只加一层烈毒、手机首次点击只展开、不发送出牌动作。

**手机画面是 Windows 上的手机布局开关，不是 Android 安装包或实体手机。** 没有据此承诺帧率、发热、长局性能或双客户端同步。本轮 QA 固定测试阵容、暂停测试驱动的自动推进，并在截图时把倒计时文本设为 76 秒，方便对照；游戏没有新增暂停功能。后续发布仍须检查真实 APK、EXE 与联机。

带 `-qa` 的三张图采用运行期“验证牌”定义和已有图作为测试探针，**不是待发布新卡的名字、数值或美术**。这些定义只存在测试进程，不写入 `data` 或正式共享池。
