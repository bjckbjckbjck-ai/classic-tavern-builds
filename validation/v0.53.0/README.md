# v0.53.0 验证

2026-09-21，Godot4.6.1，3d分支。13套403项功能/UI断言全部通过，含37项新增机制检查。日志见logs/results.json；未做平衡模拟。

- 新机制：狼爹当前/后续召唤、塔隆完整身体去重；熊爸爸延迟空位与金色；圆头全场亡语；独立适配叠层；卫星磁力/B-box；唤魔师施法与三连；诗心记忆；证书选择与权重；罪碑复制/满手/回合限次/战斗发现；古夫购买随从及法术计星；两种畸变。
- 原生界面：1280×720和1600×720设置；双端布局、图片加载、饰品读字/确认、剩余计数；入场4秒仍有名称/规则，6秒退场，不拦截输入、不改倒计时。包含既有八格/发现查看战场及双端手牌回归。
- 最终EXE：同机两个独立进程，购买、上阵、法术购买/指定/施放、战斗回放、私有快照、断线机器人接管通过。本次两个进程正常退出，无脚本/着色器错误。
- 最终APK：API33 x86_64模拟器、host GPU。与0.52.1签名SHA256一致，覆盖安装code57成功。实际触控进入畸变菜单、指定畸变、连接本机主机；拖买/古夫进度、手机首次点击展开、拖出火铸唤魔师、选购小/大饰品、发现熊爸爸获得两个不同UID均通过。6项动作/日志断言见android-actions.json。Android上新原画及叠层标记可见。
- 启动有旧shader缓存失效后重编译提示；随后Android 3D呈现验证通过，无SCRIPT ERROR或SHADER ERROR。
