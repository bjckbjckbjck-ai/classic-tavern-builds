## 性能

RTX5060 Laptop、Compatibility、画质中、上限60fps。固定桌面短效果各240帧：关闭/开启P95约16.697/16.704ms。狼爹完整入场分别360帧、开启组连续3次（包含冷载入）：P95均16.692ms，P99为16.728/16.840ms，最长16.841/19.960ms；全渲染纹理监控110249698/114099854bytes。见frame-samples.json和full-frame-samples.json。帧间隔包含调度等待，不等于GPU耗时，短样本不是长局稳定性保证。

理论新增RGBA8素材上界约6.1MiB（5张480方图保守估计，加1张576×768完成态，不含驱动内部副本），实际全场纹理读数单独记录。没有用WebP压缩文件大小冒充显存。
