## 联机范围

最多八个席位、自由选英雄（允许重复）、空位由房主添加 BOT。加入者断线后机器人托管，不支持本场重连接管；房主退出则房间关闭，无主机迁移。对局开始后不能中途加入。联机跳过动画只影响本机，等待统一阶段转换，本场阵亡不能跳过。

房主结算所有规则；客户端只提交操作，接收自己的手牌、商店及战斗回放。采用 WebSocket，版本必须一致。本版面向好友局域网体验，没有提供公网账号或中继服务。

这是跨版本全明星原卡精选与叠层适配，不是完整原版移植。七族实体副本总数各 144，尚不代表各族强度已完全均衡。特殊改动见卡牌详情与卡池文档。极端连锁有明确计算上限，达到时本场平局。对局最多 60 回合。

## 开发、扩展和验证

Windows 扩展放 EXE 同级 `mods/*.json`；房主验证后的卡池同步给客户端。五种层数使用 `charges` / `gold_charges`。详见本地 EXTENDING.md。
