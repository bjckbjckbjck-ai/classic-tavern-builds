# v0.24.0 饰品体验与交互修复

[Android APK 完整下载](https://github.com/bjckbjckbjck-ai/classic-tavern-builds/releases/download/v0.24.0/ClassicTavern-v0.24.0.apk)

[Windows EXE 完整下载](https://github.com/bjckbjckbjck-ai/classic-tavern-builds/releases/download/v0.24.0/ClassicTavern-v0.24.0.exe)

单机：主菜单可开关饰品，进入酒馆选择英雄后和七名机器人对战。饰品开启时第6／9回合选购小／大饰品。
联机：双方使用 v0.24.0，在同一 Wi-Fi / 局域网中，一人点击「好友联机 → 创建房间」，其他人输入房间显示的房主 IPv4 地址和端口（默认 4271）加入。Windows 首次询问网络访问时允许当前私人网络。房主添加机器人、选择 BOT 难度和饰品开关后开始。手机也能创建房间。

EXE 内嵌游戏资源，下载后直接运行；APK 使用原包名和签名，可覆盖旧版。系统更新由用户确认，不自动安装。
这是客户端主动建房的局域网版本，没有持续运行的公网服务器。远程不同网络需要双方已有的虚拟局域网，或自行提供可达 WebSocket 地址；本版未部署公网中继。

## 联机范围

最多八个席位、自由选英雄（允许重复）、空位由房主添加 BOT。加入者断线后机器人托管，不支持本场重连接管；房主退出则房间关闭，无主机迁移。对局开始后不能中途加入。联机跳过动画只影响本机，等待统一阶段转换，本场阵亡不能跳过。

房主结算所有规则；客户端只提交操作，接收自己的手牌、商店及战斗回放。采用 WebSocket，版本必须一致。本版面向好友局域网体验，没有提供公网账号或中继服务。

这是跨版本全明星原卡精选与叠层适配，不是完整原版移植。七族实体副本总数各 144，尚不代表各族强度已完全均衡。特殊改动见卡牌详情与卡池文档。极端连锁有明确计算上限，达到时本场平局。对局最多 60 回合。

## 开发、扩展和验证

用 Godot 4.6.1 打开 project.godot。运行 `构建.ps1` 同步公告、导入、执行检查并导出 EXE/APK。`python scripts/verify.py` 为带超时的全部回归；`python scripts/network_smoke.py <EXE路径>` 验证实际导出程序的双进程联机。

Windows 扩展放 EXE 同级 `mods/*.json`；房主验证后的卡池同步给客户端。五种层数使用 `charges` / `gold_charges`。详见本地 EXTENDING.md。

验证项目包括规则、拖动、声光事件、英雄计数、结算时序、双进程联机与 Android 13 模拟器；实际结果见 VERIFICATION.md。实体手机与两台实体机器的 Wi-Fi、高延迟公网环境尚未实测。
