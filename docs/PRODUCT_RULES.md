# 已确认服务化需求（2026-09-24）

本文件保留最初需求及尚未实现的目标；实际实现以DEPLOYED.md、ISSUE33.md和product-policy.json为准。2026-09-26按Issue #33调整为：未满8人的当前队列全员同意后一起补AI；好友房主开始后选英雄；每位玩家独立结束回放并进入酒馆。

## 两种模式与固定4桌

- 固定4个云服逻辑桌位，每桌8席，好友房间与在线匹配共享，合计32个对局席位。等待好友、预留、进行中、重连保留均占桌，不能开第5桌；大厅/排队上限另设。
- 主界面两个联机入口：好友房间、在线匹配。单机保持可用。
- 好友房间复用当前LAN玩法体验：房主创建、房间码加入、可选密码、指定畸变/饰品/AI难度等设置、添加移除BOT、手动开局；不计在线积分。云服运行规则，房主电脑退出不关闭整桌。
- 既有纯本地LAN可以保留，不计云服4桌；没有云服参与的LAN房主进程消失，不承诺由云服恢复。
- 桌位原子预留，空等人房建议10分钟无活动提醒后释放；4桌占满时显示等待桌位，补AI也不能绕过容量。好友创建与匹配分配按请求时间公平占桌。

## 在线匹配与积分

- 首版按版本/公共玩法分池、FIFO凑8人；记录积分先于按分差分段匹配，避免低在线量难以成局。
- 从进入本次队列开始60秒仍未成局时，提示“继续等真人 / 接受最高难度AI / 取消匹配”。拒绝或没有回答继续等真人，不能自动补AI。
- 混合局每位真人都必须显式同意；同意只对本次排队生效，可在分配前撤回。优先凑全真人局，拒绝者保留原等待时间。凑齐/取消/同意并发只能提交一次状态转移。
- AI选择当前版本最高难度“霸主”，不硬编码易变化的编号；说明其规则优势及该局计分方式。
- 所有在线局由权威服务器按最终名次结算。建议全真人名次1—8：+70、+45、+25、+10、-10、-25、-45、-70，初始1000、最低0；这是未平衡验证的数值草案。
- AI混合局积分策略待用户选择；建议降系数并限制单人刷分。具体系数、限制和四舍五入方式发布前明确，写入计分规则版本，不能静默改变历史账本。
- account_id+match_id唯一约束，结果与积分账本同一事务，重试不重复加分。AI不建真人账号、不进排行榜。
- 真人掉线仍按本人最终名次结算，不能拔网线逃扣分；临时托管不把全真人局改为混合局。服务器异常中止不按普通败局扣分。

## 双模式托管重连

- 账号→稳定席位→临时peer ID分离。真人身份与当前控制者分离，不能把托管玩家当成永久AI过滤掉结果。
- 断线检测后AI托管，计时继续；本场结束前可以重新登录回到原席位，替代旧120秒后释放席位方案。
- 接管递增连接代次，旧连接不能再操作；按action_id去重及状态版本校验。AI与真人只能有一个写入者，已完成的AI操作不回滚。
- 重连发送自己的最新快照、倒计时和阶段；战斗不重掷随机数。覆盖发现、抉择、饰品、战斗回放、淘汰观战和结算。
- 房主短断保留管理权，长离线移交在线真人，返回不抢回管理权；具体时限配置化。开局后设置冻结。
- 等人阶段掉线席位短时保留后可释放；已开局全部真人断线也托管至终局，不立即重置，按游戏回合上限结束。
- 桌进程存活时支持重连；进程/主机崩溃后的半局恢复后置。数据库灾备保证账号/积分/战绩恢复，不等于恢复半场比赛。

## 云端持久化与每日异地备份

- 云端PostgreSQL保存账号密码哈希、用户设置、积分账本、战绩、会话及房间归属。首版同时实现注册登录、一次性恢复码和会话撤销。
- 每天生成一致性数据库归档，默认建议北京时间04:00（待确认）。携带数据库版本、游戏/服务/协议版本、产物清单及恢复说明，不包含明文密码。
- 先用接收电脑公钥加密；解密私钥只在本地并由用户离线另存。传输临时文件，校验完整性后原子改名并回执，收到回执才标记异地成功。
- 本地可达时云端通过受限SFTP推送；NAT不可达时用私网或本地任务拉取云端加密归档，实现每日送达。未经确认不开放本地公网SSH。
- 电脑离线时云端保留待传并重试；电脑上线补传。展示最后生成/送达/恢复演练时间，过期或磁盘不足告警。
- 建议云端7天且不删除未送达项；本地30天+12份月备份。离线积压导致空间不足时告警，不能静默删未送达备份。
- 每日备份的正常恢复点缺口可接近24小时；本地离线会扩大异地缺口。不是实时同步。
- 灾备步骤：停止写入→校验解密→隔离/干净数据库恢复→核对schema和产物→撤销全部登录会话→旧活跃局标记异常→核对账号与积分→重新开放；不重复结算旧局。
- 首次上线要实际做隔离数据库恢复演练，下载成功不等于可恢复。签名/加密密钥与备份的恢复依赖单独列清单。

## 实施顺序与验收

1. 拆无界面Linux专服、稳定席位与连接映射，保证单机/LAN不回退。
2. 账号及两个主界面入口；好友房间设置及固定4桌原子调度。
3. 在线匹配60秒询问、最高难度AI、权威名次与幂等积分账本。
4. 双模式托管重连及全员断线生命周期。
5. 一键安装/更新/维护排空/回滚；每日异地备份及真实恢复演练。
6. 32真实协议客户端、4桌混合模式连续至少2小时，验证第5桌不超开；59/60秒边界、拒绝/无响应不补AI、重复结果不计分、两种外网客户端重连、电脑离线补传和故障回滚。

尚待信息：AI混合局积分偏好、每日备份时间、接收电脑系统/目录/在线时间与可达方式。服务器和目标电脑均未连接，未创建任何实际定时备份任务。

## service6 明确退出与公开观战补充

临时断线仍按原规则托管并保留重连。明确选择“彻底退出”后解除账号绑定，不能重新参赛，席位由 AI 继续；所有真人都明确退出则释放桌位。未淘汰的积分赛退局按第 8 名、已淘汰按实际名次结算且只结算一次。两种房型在服务器列表中明确标注，等待中的好友房可加入；观众不占参赛席位且只接收公开信息，每桌观众连接上限 8，不表示已完成此额外容量的压测。详见 ROOMS-SPECTATORS.md。
